HOW IT WORKS

From image to quality decision

  1. 01
    Validate image

    The server verifies the file and reads it without permanently saving it.

  2. 02
    Prepare input

    The image is converted to RGB and resized to the model’s configured dimensions.

  3. 03
    Run inference

    The classifier returns the probability that the casting is defective.

  4. 04
    Apply threshold

    The validation-selected threshold converts the probability into the final decision.

Research prototype limitation

This system performs binary classification only. It does not identify a specific defect type or guarantee production conformity. Real factory use requires external validation, monitoring, and a documented human-review process.
