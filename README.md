# Automated Casting Defect Detection Using Deep Learning and Computer Vision

## Week 1 Objective
This Week 1 package proves project setup, planning and GitHub activity for all 5 team members.

## Project Aim
To build a computer-vision system that classifies casting product images into `def_front` and `ok_front`, compares deep-learning models, uses Grad-CAM explainability and prepares a Gradio demo.
