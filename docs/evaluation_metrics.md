# Evaluation Metrics Plan

| Metric | Purpose |
|---|---|
| Accuracy | Overall correctness |
| Precision | Reliability of predicted classes |
| Recall | Ability to identify actual class cases |
| F1-score | Balance between precision and recall |
| AUC | Probability separation quality |
| Confusion matrix | False positive/negative review |
| Inference time | Deployment speed |
| Model size | Deployment practicality |

Priority: defective-class recall, because missed defects are risky.
