# System Architecture

```text
Dataset
 → EDA + Quality Checks
 → Preprocessing
 → Train/Val/Test Split
 → Baseline CNN / Xception / Comparison Models / Optional YOLO
 → Technical Evaluation
 → Error Analysis
 → Best Model Selection
 → Grad-CAM Explainability
 → Saved Best Model
 → Gradio Demo App
 → Human-in-the-loop Review
```

## GitHub Evidence Layer
Every stage must be supported by commits, issues, project board updates, meeting notes and README updates.
