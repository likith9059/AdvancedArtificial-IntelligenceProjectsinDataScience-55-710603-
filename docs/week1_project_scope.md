# Week 1 Project Scope

## Problem
Manual casting product inspection can be slow, inconsistent and affected by fatigue, lighting and inspector experience.

## Solution
A deep-learning computer-vision system will classify casting images as defective or OK and provide Grad-CAM visual explanation for human review.

## In Scope
- Binary image classification
- Kaggle/Roboflow secondary image data
- EDA and quality checks
- Baseline CNN and Xception
- Model comparison
- Grad-CAM
- Gradio demo
- GitHub evidence

## Out of Scope in Week 1
- Training final model
- Claiming accuracy
- Final deployment
